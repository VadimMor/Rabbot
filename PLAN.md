## DOCKER

Docker нужен, чтобы изолированно развернуть и управлять базами данных и брокером сообщений, не засоряя основную операционную систему, а в перспективе — для контейнеризации самих микросервисов Spring Boot 

- [x] docker-compose.yml
    - [x] PostgreSQL с pgvecto - нужен для долгосрочной памяти агентов и хранения реляционных данных
    - [x] Redis - нужен для кэширования ответов внешних API, Rate Limiting и хранения сессий
    - [x] RabbitMQ с rabbitmq_management - нужен для асинхронного обмена сообщениями между микросервисами и визуального интерфейса мониторинга очередей
